# Bug Hunting — краткое содержание

Учебный проект RS School (Fullstack Engineering, неделя 5). Пять готовых страниц, в CSS и JS спрятаны баги. Задача — починить поведение по таблице в корневом `README.md`.

HTML на всех страницах уже правильный: он показывает, как страница должна выглядеть и работать. Менять нужно стили и скрипты, не разметку.

## Стек

HTML5, CSS3, чистый JavaScript. Сборки и библиотек нет: страницы открываются в браузере как есть.

## Задания

Всего 45 багов. Сложность растёт от первого к последнему.

| Папка | Страница | Где баги | Сколько |
|---|---|---|---|
| `1-pricing` | Тарифы Basic / Pro / Enterprise | CSS | 8 |
| `2-portfolio` | Галерея проектов | CSS | 7 |
| `3-todo` | Список задач | JS | 10 |
| `4-cart` | Корзина, промокод `SALE10` | JS | 10 |
| `5-catalog` | Поиск, категория, сортировка по цене | JS | 10 |

На главной карточке первого задания написано «7 багов». В `README.md` их восемь: седьмой пункт — кнопки «Выбрать» на одной высоте — добавлен отдельно.

## Как сдавать

Ветка для правок — `fix/bugs`. Коммиты по ходу работы, затем pull request из `fix/bugs` в `main` своего форка.
